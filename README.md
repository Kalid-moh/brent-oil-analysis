# brent-oil-analysis

## Overview

This repository contains an exploratory analysis of Brent crude oil prices and detected events in the price series. The goal is to load, preprocess, and analyze price data to detect significant events and produce reproducible results in the supplied notebook.

## Data

- **Raw:** `Data/raw/BrentOilPrices.csv` — daily Brent oil prices as downloaded from the original source.
- **Processed:** `Data/processed/detected_events.csv` — events detected by the analysis pipeline (generated by the notebooks/scripts).

## Repository Structure

- `notebooks/` : Jupyter notebooks for the analysis (start with `notebooks/task-1.ipynb`).
- `src/` : Python source code and helper modules (if present).
- `Data/raw/` : Raw input CSV files.
- `Data/processed/` : Processed outputs and event detection results.
- `requirements.txt` : Python dependencies for reproducing the analysis.

## Setup

1. Create a Python environment (recommended Python 3.8+).
2. Install dependencies:

```
pip install -r requirements.txt
```

## Usage

- Open and run `notebooks/task-1.ipynb` in Jupyter or JupyterLab to reproduce the core analysis and visualizations.
- If there are scripts in `src/`, run them as Python modules (examples are documented in the notebooks).

## Reproducibility

- Ensure the raw data file `Data/raw/BrentOilPrices.csv` is present.
- Run the notebook cells top-to-bottom to regenerate `Data/processed/detected_events.csv` and figures.

## Notes & Next Steps

- The notebooks include exploratory plots and the event detection procedure; review the top cells for configuration options (date ranges, smoothing parameters).
- To automate the pipeline, consider adding CLI scripts under `src/` and a small runner that outputs processed CSVs and images.
